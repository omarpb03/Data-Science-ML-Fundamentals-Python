# Data Science & Machine Learning Fundamentals 📊

Este repositorio contiene una colección de proyectos y notebooks que documentan el ciclo de vida completo de la Ciencia de Datos: desde la manipulación y limpieza de datos (ETL básico) hasta la implementación y evaluación de modelos de Machine Learning clásico.

El enfoque de este repositorio es analítico y cuantitativo, priorizando la calidad de la información y la correcta interpretación estadística de los algoritmos.

## 🛠️ Stack de Tecnologías
- **Manipulación de Datos:** Pandas, NumPy.
- **Visualización:** Matplotlib, Seaborn.
- **Machine Learning Clásico:** Scikit-learn.
- **Entorno:** Jupyter Notebooks.

## 📂 Estructura del Pipeline de Datos

Los notebooks están organizados siguiendo la metodología estándar de un proyecto de Data Science:

### 1. Manipulación y Análisis Exploratorio (EDA)
El preprocesamiento es la base de cualquier modelo robusto.
- **`pandas_fundamentals.ipynb`**: Técnicas esenciales de manipulación de DataFrames y limpieza de datos.
- **`visualizacion.ipynb`**: Análisis exploratorio de datos (EDA) mediante gráficos estadísticos para identificar distribuciones y correlaciones.

### 2. Calidad de Datos (Data Quality)
Tratamiento riguroso de anomalías para garantizar la fiabilidad de los modelos.
- **`Calidad de Datos 2026-01 (1).ipynb`**: Profiling, estandarización y validación de la integridad del dataset.
- **`Outliers y Missings.ipynb`**: Técnicas matemáticas y estadísticas para la imputación de valores nulos y el manejo de valores atípicos (outliers).

### 3. Modelos de Regresión (Predicción Continua)
- **`SimpleLinearRegression.ipynb`**: Fundamentos estadísticos de la regresión y función de costo.
- **`MultipleLinearRegression.ipynb`**: Extensión a múltiples variables, evaluación de multicolinealidad y métricas de error (MSE, RMSE, R²).

### 4. Modelos de Clasificación
- **`Arboles_de_decision.ipynb` / `Arboles de Decision - Ejemplo.ipynb`**: Construcción de reglas lógicas, entropía y ganancia de información.
- **`KNN Ejemplo.ipynb`**: Algoritmo K-Nearest Neighbors para clasificación basada en distancias y optimización del hiperparámetro 'K'.

### 5. Introducción a Redes Neuronales
- **`ANN.ipynb`**: Conceptos introductorios de Redes Neuronales Artificiales (Artificial Neural Networks) como puente hacia modelos de Deep Learning.
